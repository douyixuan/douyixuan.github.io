记下值得留下的要点。一个概念、一个发现、一个问题，都可以从几句话开始。

## 记录准则

- **一页一件事。** 围绕一个概念或问题写；出现另一个独立主题，就拆出去并链接。
- **先写自己的理解。** 留下结论、适用条件和容易混淆的地方，不为凑篇幅补背景。
- **短，但能看懂。** 一句话也可以；让未来的自己知道它是什么意思、什么时候有用。
- **区分事实与猜想。** 实测结论写明环境，未验证的想法直接标注，问题可以暂时没有答案。
- **留下来源和关联。** 引用附原始链接；想到已有笔记就连过去，不强行为每个词建页面。
- **持续修订，避免重复。** 新理解补到原笔记；完整推导、实验过程或长文放在 Blog，再从这里链接过去。

## 新建笔记规范

1. 先搜索是否已有同一主题，优先更新已有笔记。
2. 标题用具体的概念、问题或判断；文件名用简短的英文小写词，以连字符分隔，保持链接稳定。
3. 写一句摘要，再记 1–5 个要点。有必要时补最小示例、适用条件或待确认的问题。
4. 来源使用可访问的原始链接；站内关联使用 Hugo 的 `relref`，指向已存在的页面。暂时没有关联时，省略该项。
5. 发布前删除模板提示和空小节，确认摘要不是占位文字、链接有效，再将 `draft` 改为 `false`。
6. 后续修改继续编辑原笔记，并更新 `lastmod`；不要为同一概念再建一篇。

### 新建命令

在博客仓库根目录运行：

```bash
hugo new content --kind second-brain second-brain/<slug>.md
```

模板默认生成草稿，包含标题、日期、更新日期、摘要和可选的要点、来源、关联小节。创建后按需要删减，不必填满所有小节。

这个专栏从空白开始，只收录真正值得再次翻阅的笔记。

写法参考：[Anthony Morris 的 Second Brain](https://anthonymorris.dev/second-brain)。
