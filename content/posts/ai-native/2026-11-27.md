今天选取两篇 11 月 24 日发布的原创案例与研究，分别讨论 Agent 执行基础设施和模型框架的组合选型。

## 1. How iFood scales coding agents across 15,000 repositories

- **作者/来源：** OpenAI × iFood（访谈 Victor Coelho，未单列个人作者）
- **发布日期：** 2026-11-24
- **原文：** https://openai.com/business/customer-stories/ifood/
- **相关技术：** Remote Agents Platform、REST API、Sandbox、Structured Outputs

**推荐理由：** 当重复维护需求遍布大量仓库时，统一执行基础设施比各团队自行搭建 Agent 更有复用价值。这个案例展示如何将代码任务变成异步服务。

**3 条核心要点：**

1. **确定性操作包围非确定性执行。** REST API 接收任务及环境要求，独立远程 sandbox 负责执行；克隆仓库、导入技能、建立分支及发布 merge request 由固定流程承担，模型负责中间需要判断的工作。
2. **结构化结果与异步交付。** 调用方可追踪任务进度，稍后获取制品；Structured Outputs 约束返回格式，区分成功与失败，但格式正确不代表代码已经通过独立验收。
3. **规模与费用。** 案例报告覆盖超过 15,000 个仓库、完成超过 25,000 次运行，平均模型推理费用约 0.04 美元/次；安全平台修复准确性与解决漏洞数量均超过原来的两倍。未披露完整基础设施成本、统一分母或独立对照，不能推广为所有编码任务的收益。

> **核心启示：** 将执行环境、生命周期和制品管理做成共享服务，而非每个团队重复实现。

## 2. ShellBench: What Matters More for AI Agents, Models, or Harness for Everyday Tasks

- **作者/来源：** Vincent Koc、Aditya Washikar、Rishab Naveen Venkataraman 等 22 位作者 / OpenClaw Foundation、Parsewave、Hugging Face、Paradigm、UC Berkeley、Columbia University、Red Hat、NVIDIA
- **首次提交：** 2026-11-24 16:48:06 UTC（北京时间 11 月 25 日）
- **原文（arXiv）：** https://arxiv.org/abs/2611.32946
- **AlphaXiv：** https://www.alphaxiv.org/abs/2611.32946
- **相关技术：** Harbor、Agent Harness、Pass@1、LLM Judge

**推荐理由：** 在文件丰富、来源冲突的个人助理任务中同时比较模型、框架和推理预算，避免根据单一榜单或单次成功选择系统配置。

**3 条核心要点：**

1. **控制变量的组合评测。** 从逾千万匿名用户请求归纳出 100 个任务，工作区文件数中位数 188；12 个模型、5 个 Harness、3 档推理力度共 53,100 次运行（一个不兼容组合除外）。90 题用模型评分，10 题用代码测试，20 题计划公开。
2. **模型差异大于框架均值差异，但组合仍重要。** 模型平均通过率跨度 18.8%–62.5%，五个框架在共同测试模型上的均值为 42.9%–45.2%；单个模型与框架的配对仍有较大差异。GPT-6.1 Sol 为 61.4%，GPT-6 Astra 为 62.5%，前者估算单次 Token 费用约为后者六分之一，并非真实账单。
3. **评分器存在测量边界。** 278 项有人工共识的评分判定中，模型裁判一致率为 89.9%；这是单项判定而非整题准确率。研究任务为个人助理场景，且部分作者参与 OpenClaw 维护，结论不能直接外推到复杂编码或生产安全。

> **核心启示：** 针对实际任务分布联合选择模型与 Harness，并单独验证费用、可靠性和安全性。

## 今日思考

共享执行平台解决任务在哪里运行、如何追踪以及如何交付；受控组合评测解决用什么模型和框架运行。建议将 Task API → Isolated Runtime → Versioned Model/Harness → Independent Acceptance → Cost and Reliability Telemetry 作为待验证的架构，把推理费用与完整交付成本区分开。

**证据边界：** iFood 为厂商客户案例；ShellBench 为预印本，未独立复现实验。arXiv 元数据及 HTML 原文已核对，AlphaXiv 文献连接返回匹配全文，标准网页独立 HTTP 访问未成功。
