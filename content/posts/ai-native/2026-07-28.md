## 1. When Coding Stops Being the Bottleneck

- **作者/来源：** Hao Wang 等 / Berkeley RDI
- **发布日期：** 2026-07-26
- **原文：** https://rdi.berkeley.edu/blog/auto-software-dev/

**推荐理由：** 不是讨论 coding agent 的局部提效，而是重新定义代码生成不再稀缺后，软件工程的责任边界。

**核心要点：**

- 软件自主性可分为代码自治、流水线自治和需求自治。
- 当实现成本下降，规格、约束、架构决策和验证体系会成为主要工程资产。
- Agent 能完成单次功能，但长期演进仍容易出现规格与实现漂移，需要 repository-scale 的持续评测。

## 2. The Future of Engineering: Agentic Engineering 2.0

- **作者/来源：** Zohar Einy / Port
- **发布日期：** 2026-07-23
- **原文：** https://www.port.io/blog/agentic-engineering-2-0

**推荐理由：** 清晰区分固定工作流与自主 agent loop，并把 context、tools、guardrails 和治理放到同一个工程框架中。

**核心要点：**

- 1.0 预先设计工作流图，2.0 只提供目标，让 agent 自己选择路径。
- Agent 的基础设施可以归纳为目标、上下文、工具和 guardrails。
- 工程师的工作从设计每个步骤，转向维护上下文、技能、权限边界、执行轨迹和验收标准。
