## 1. Scientific Computing in the Age of Agentic AI

- **作者/来源：** OpenAI
- **发布日期：** 2026-07-28
- **原文：** https://openai.com/index/scientific-computing-agentic-ai/

**推荐理由：** 基于八个真实科学计算项目，分析 agent 如何参与软件迁移、GPU 重构、性能优化和长期维护。

**核心要点：**

- 工程师和研究人员的角色从亲自实现，转向定义目标、拆解任务和验证正确性。
- Agent 最适合具有明确验收信号的任务，例如输出一致性、性能基准和参考实现对齐。
- 降低重写成本也会产生更多无人维护的分叉，因此上游合并和长期维护责任仍不可缺少。

## 2. Agent Swarms and the New Model Economics

- **作者/来源：** Wilson Lin / Cursor
- **发布日期：** 2026-07-20
- **原文：** https://cursor.com/blog/agent-swarm-model-economics

**说明：** 超出七天窗口，但属于近期 multi-agent software factory 领域较完整的工程实践。

**推荐理由：** Cursor 公开了数百个 agent 并行构建软件时的任务树、上下文隔离、版本控制、冲突解决和 review 架构。

**核心要点：**

- Planner 只负责拆解和决策，Worker 只负责局部实现；扩展能力主要来自上下文隔离，而不只是并行计算。
- 人类时代的 Git 和 code review 难以承受极高提交频率，需要 agent-native VCS 和独立冲突解决机制。
- 多种 review 视角、共享设计文档和由 agent 维护的 Field Guide，有助于控制长期漂移。
