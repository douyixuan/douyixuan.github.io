## 1. Bots for the last mile: Rollouts, Security Review

- **作者/来源：** Rustam Lalkaka / Cursor
- **发布日期：** 2026-09-23
- **原文：** https://cursor.com/blog/rollouts-and-security-reviewer

**推荐理由：** 这篇最重要的变化是把 coding agent 的边界从“PR 之前”推到“PR 之后”。Cursor 的判断是：代码生成已经越来越快，但真正没有同步加速的是上线前后的验证、监控、回滚和安全检查。因此它把生产 telemetry、deploy state 和 code diff 一起放进 Agent loop，开始接近真正的 software factory。

**核心要点：**
- **Rollouts 从 PR 一直跟到生产。** Agent 在 merge 前根据 diff 生成 monitoring plan，标出风险、预期行为和 instrumentation 缺口；部署后再把真实指标与 pre-deploy baseline 比较。
- **生产反馈可以直接触发下一步动作。** 当发现 regression 时，Agent 会定位可疑 change，并根据策略选择提醒作者、暂停 progressive rollout，或准备 revert PR，而不是只输出一段分析。
- **验证能力成为代码生成之后的新瓶颈。** Cursor 明确把 observability、deployment 和 remediation 纳入 Agent 的工作上下文，说明 AI-native SDLC 正从 `generate code` 迁移到 `generate → verify → observe → recover`。

> 核心启示：**Software factory 的闭环不应终止于 PR。真正的 Agentic SDLC 应覆盖 `intent → code → review → deploy → observe → diagnose → recover`。**

## 2. Introducing the new Copilot with Home, Code and Autopilot

- **作者/来源：** Jared Spataro / Microsoft
- **发布日期：** 2026-09-25
- **原文：** https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/

**推荐理由：** 这篇产品发布里最值得关注的不是 Copilot UI，而是 Microsoft 对长期 Agent runtime 的系统建模。Autopilot 被设计成一个长期运行的数字协作者：有独立 identity、memory、computer 和 workspace；Code 则把生成的软件放进受治理的 managed runtime。它把“Agent 是一个聊天窗口”进一步推进到“Agent 是组织内部长期存在、可治理的计算主体”。

**核心要点：**
- **Autopilot 是 persistent agent，而不是一次 session。** 用户给它 role、goal 和 boundary 后，它可以持续监听渠道、跟进线程、执行 recurring work，并在几天后继续项目；运行状态由独立 identity、memory、computer 和 workspace 承载。
- **Runtime 成为 AI-native 产品的一等基础设施。** Code 在 sandbox 中运行，Microsoft Copilot Managed Runtime 负责把生成的 app/workflow 托管在企业环境里，并复用于 Cowork、Code、Copilot Studio 和第三方/pro-code 开发者。
- **Context、权限、治理和成本进入同一控制面。** Microsoft IQ 提供组织上下文；Agent 运行在 tenant 权限和 audit/governance 下；FinOps for AI 则给长期 Agent 加上 usage-based billing、模型策略和 spending policy。

> 核心启示：**长期 Agent 平台正在收敛成一种新的运行时抽象：`identity + memory + computer + workspace + context + permissions + audit + cost control`。模型只是其中可替换的一层。**
