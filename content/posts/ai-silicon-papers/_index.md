**读懂论文，保留问题。** 每日读一篇相关论文，关注作者提出了什么问题、如何论证，以及留下了哪些值得继续思考的疑问。

| 方向 | 关注的问题 |
| --- | --- |
| AI for Silicon / EDA | Agent 如何生成、优化与验证硬件设计？ |
| 编译器与 GPU 工具链 | AI 如何参与程序变换、kernel 优化与工具链测试？ |
| 规格、验证与评测 | 如何表达约束、构造可靠反馈、识别错误与评测漏洞？ |
| 知识与工程工作流 | 如何沉淀领域经验、组织工具调用、衡量可靠性与成本？ |

每篇包含论文定位、简短中文导读、arXiv / 全文 / **alphaXiv** 入口、阅读路线、思想启发，以及 **3 个思考问题**；参考思路默认折叠。优先开放全文和有实验依据的工作，也收录能明确提出研究问题的观点论文，并区分作者结论、作者预测和导读者的延伸。

新论文与经典工作结合，按论文编号去重。没有合适新作时回读经典，不以新闻凑数。
